# Standard workflow YAML examples

These YAML files operate only on standard pypost data. Copy a directory to a writable project area before editing it; sample data under `sciplot/demos/` is the canonical source for bundled synthetic demonstrations.

- `curve/` — Data1D conversion and curve plotting.
- `data3d/` — normalized 3-D time-series conversion and Data3D v1 processing.
- `q/` — Q surface extraction/rendering workflows.

Solver-specific binary input is deliberately absent here; use the corresponding directory under `examples/converters/` first.
